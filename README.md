# BMI Calculator

A simple and user-friendly web application that calculates Body Mass Index (BMI) based on a user's height and weight.

## About the Project

The BMI Calculator is a browser-based application designed to make BMI calculation simple and accessible.

Users can enter their height and weight to calculate their BMI and view the resulting value.

## Features

- **BMI Calculation** – Calculate Body Mass Index using height and weight.
- **User Input** – Enter height and weight through a simple interface.
- **Result Display** – Display the calculated BMI result.
- **Responsive Design** – Access the application through a web browser.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Purpose

This project was developed to practise fundamental web development skills, JavaScript calculations and user interface design.

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter your height and weight to calculate your BMI.
